## Descripción

Este proyecto consiste en el desarrollo de un sitio web dinámico utilizando PHP. Su propósito es demostrar el funcionamiento de diferentes elementos fundamentales del lenguaje mediante ejemplos prácticos y páginas independientes.

El sitio cuenta con un diseño compartido, un menú de navegación y un apartado que muestra información de la sesión del usuario.

## Temas implementados

1. Variables.
2. Tipos de datos.
3. Estructuras condicionales `if`, `elseif` y `else`.
4. Estructura `switch`.
5. Ciclo `for`.
6. Ciclo `while`.
7. Ciclo `foreach`.
8. Arreglos.
9. Arreglos multidimensionales.
10. Manejo de sesiones con PHP.

## Ejecución local

1. Instalar PHP.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar el siguiente comando:

```bash
php -S 127.0.0.1:8888
```

4. Abrir el navegador y acceder a:

```text
http://127.0.0.1:8888
```
